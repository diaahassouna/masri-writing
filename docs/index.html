Masri

A writing system for Egyptian Arabic

Masri is a proposed canonical orthography for Egyptian Arabic — a standardized way to write the spoken language, designed to normalize Arabic-script, Franco/Arabizi, and mixed writing into one consistent form.

Masri is a developing, proposed writing-system project. Its specification, examples, and tools are being refined iteratively — it is not an officially adopted national standard.
🔥 Try Masri How it works

What is Masri?

Egyptian Arabic is spoken by tens of millions of people every day but has no single standard way to write it. Arabic script carries it informally; Franco/Arabizi fills the online gap, but every writer spells the same word differently. Masri proposes one canonical form the spoken language can be written in — then represented as ASCII-friendly Tier 1, full Tier 2, or Latin-romanized DTS depending on where you're typing.

Why Masri?

Canonical Masri is distinct from informal input — Franco is a starting point, not the standard itself.
Regular sound-to-symbol correspondence, with explicit rules — not silent guesses — for the contextual and lexical exceptions.
One orthography, three representations: Tier 1 (ASCII), Tier 2 (full), and DTS (romanized) all describe the same underlying system.
No digit ever stands in for a letter — a deliberate break from Franco's 3/7/2 numeral conventions.
