Arabic-V — The Vocalized Arabic Representation of Masri

Arabic-V is the canonical, vocalized, Egyptian-oriented Arabic-script representation of Masri — Harakat/Tashkeel, mandatory sukūn, shadda-based doubling, and dedicated Egyptian realization markers, all Unicode-defined. It is not a separate tier or a competing orthography; it is one of the five Masri representations of the single canonical system, alongside Masri Standard, DRS, Masri Basic, and Arabic-P.

Status: Arabic-V is canonical and established. This page documents its rule set — Rule IDs prefixed AV- — plus the Unicode code points and worked examples an implementation needs. Areas still open for formal specification are listed in §29.

1. Masri and its representations

Masri is one underlying canonical orthographic system with multiple representations.

RepresentationPurpose
Masri StandardPrimary public Latin representation
DRS — Diaa Romanization SystemTechnical Latin representation
Arabic-VCanonical vocalized Arabic-script representation
Masri BasicASCII-compatible practical fallback
Arabic-PPlain Arabic-script practical fallback

Only Masri Basic / Tier 1 and Masri Standard / Tier 2 are called tiers. The relationship is one canonical Masri system, shown as Masri Standard, DRS, Arabic-V, Masri Basic, and Arabic-P in turn. Arabic-V therefore represents the canonical Masri system in Arabic script; it does not create a different orthography. See the Representations page for how all five relate.

2. What Arabic-V is for

Arabic-V provides an explicit Arabic-script representation for situations where ordinary unvocalized Arabic does not provide enough information. Its purposes include:

  • representing Egyptian pronunciation explicitly
  • showing vowels that Arabic-P leaves implicit
  • showing final consonants with no following vowel
  • representing consonant and vowel doubling
  • preserving underlying letters where useful
  • representing Cairene pronunciation mergers
  • representing Egyptian-specific vowels
  • representing foreign vocabulary according to pronunciation
  • providing an Arabic-script counterpart to Masri Standard
  • supporting linguistic and computational analysis

Arabic-V is therefore not simply Arabic-P + Tashkeel. It is a dedicated Masri representation.

3. Arabic-P versus Arabic-V

Arabic-P — Plain Arabic is ordinary Arabic script without explicit vocalization, e.g. أسانسير. It is familiar, fast, and practical, but pronunciation information may remain implicit.

Arabic-V — Vocalized Arabic explicitly represents the Masri pronunciation. Conceptually, Masri Standard maps to Arabic-V the way it maps to any other representation — rather than asking the reader to infer missing vowels, Arabic-V writes them.

The distinction is Arabic-P → practical and familiar versus Arabic-V → explicit and informative. Arabic-P is not wrong, and Arabic-V is not simply "better Arabic". They serve different purposes.

4. The fundamental Arabic-V principle

Arabic-V follows one central principle:

Write the canonical Masri sequence explicitly.

This means that Arabic-V represents:

  1. the consonant
  2. its vowel, where applicable
  3. doubling, where applicable
  4. absence of a following vowel through sukūn
  5. Egyptian-specific realization information where required

This makes Arabic-V structurally different from ordinary Arabic spelling.

6. Mandatory sukūn

Rule AV-S01 — Mandatory Sukūn. When a consonant has no vowel after it, Arabic-V writes sukūn on that consonant. This is a fundamental difference from ordinary Arabic-P.

For example, Katab is كَتَبْ rather than simply كتب:

tتَ

bبْ

Thus K a t a b → كَتَبْ. The final بْ explicitly tells the reader that no vowel follows /b/. Sukūn is therefore not merely optional decoration. In fully specified Arabic-V, it is required whenever the consonant is not followed by a vowel.

7. Shadda means doubling

Rule AV-S02 — Shadda as Doubling. Shadda represents doubling. The element being doubled depends on what the shadda belongs to.

7.1 Consonant doubling

For consonants, Cّ = CC. Example: دّ = dd, so dd → دّ. In ywaddi → يْوَدّْي, the دّ represents the doubled consonant d + d.

7.2 Vowel doubling

For vowel carriers, shadda represents a doubled vowel: Vّ = VV. For example, ee → يّ.

The principle is consonant + shadda → doubled consonant, vowel carrier + shadda → doubled vowel. Shadda is therefore best understood as a doubling operator, not merely as a "gemination mark".

8. Long and doubled vowels

Arabic-V distinguishes ordinary vowels from doubled vowels. The Roman Masri representation uses doubled vowel letters:

The Arabic-V representation uses the appropriate Arabic vowel structure and shadda where the vowel is doubled.

9. The ee convention

Rule AV-V01 — Doubled E. The Masri sequence ee is represented through the ي vowel carrier with shadda: ee → يّ. Example: tafkeer is represented تَفْكْيّرْ — the doubled e-vowel is represented by يّ. This is not the ordinary Arabic consonantal interpretation of ي. In Arabic-V, its interpretation follows the canonical Masri vowel sequence.

10. The aa convention

Rule AV-V02 — Doubled A. The Masri sequence aa is represented by the appropriate Arabic long-a structure. Depending on the underlying canonical Masri form, this may be آ, or, where the final underlying letter is ى, by preserving that underlying letter while representing the doubled vowel: ىّٰ.

The second form consists conceptually of ى + ّ + ٰ, where ى preserves the underlying alif maqṣūrah, ّ represents doubling, and ٰ makes the long-a value explicit. Therefore Arabic-V preserves the distinction between ordinary long aa and a final aa whose underlying orthographic identity is ى.

11. The Egyptian /ɛ/ vowel

Rule AV-V03 — Yāʾ Maftūḥa. Arabic-V uses يَ to represent the Egyptian vowel /ɛ/. Its Latin correspondence is é = /ɛ/. Thus يَ = é = /ɛ/. This is a dedicated Masri vowel convention and is not to be confused with an ordinary sequence of consonantal y + a.

Example: asanséér contains the Egyptian /ɛ/ represented by يَ. The convention remains distinct from final alif maqṣūrah (§12).

12. Final alif maqṣūrah

Rule AV-V04 — Final ى. Arabic-V preserves ى where the canonical Masri representation uses final alif maqṣūrah. When its long-a value needs to be made explicit, the dagger alif may be placed above it: ى + ٰ. Where the doubled-vowel rule applies, the full representation may contain ى + ّ + ٰ.

The distinction is fundamental: ى = underlying final alif maqṣūrah; يَ = Egyptian /ɛ/. They are not interchangeable.

13. Cairene Qāf → Hamza

Rule AV-C01 — Cairene Qāf Marker. Arabic-V distinguishes between ق = /q/ and قٔ = Cairene /ʔ/. The marked form retains the underlying ق while explicitly indicating its Cairene realization as a glottal stop. The marker is U+0654 — ARABIC HAMZA ABOVE.

Therefore ق + U+0654 means: underlying ق, realized as /ʔ/ in Cairene. This is information-preserving and is different from simply replacing ق with ء.

14. Cairene ث → /s/

Rule AV-C02 — Cairene Thāʾ Marker. Arabic-V may preserve underlying ث while explicitly marking its Cairene realization as /s/. The marker is U+06DC — ARABIC SMALL HIGH SEEN. Thus ث + U+06DC means: underlying ث, realized as Egyptian /s/. The base letter remains visible.

15. Cairene ذ → /z/

Rule AV-C03 — Cairene Dhāl Marker. Likewise, ذ + U+06DC means: underlying ذ, realized as Egyptian /z/.

BaseMarkerMeaning
ثU+06DCunderlying ث → /s/
ذU+06DCunderlying ذ → /z/

The marker itself does not represent a phoneme independently. Its meaning comes from the combination base letter + realization marker.

16. Underlying-preserving versus fully merged spelling

Arabic-V allows an important distinction. An Egyptian /z/ that historically corresponds to ذ may be represented either as ذ + merger marker, or, where permitted by the canonical rules, as ز. The first preserves the underlying identity; the second is the simpler fully merged representation.

Therefore the system can provide both an information-preserving representation and a simplified Egyptian representation, without treating either approach as inherently "wrong". The final normative rules should specify which form is preferred in each context.

17. Masri J

Rule AV-C04 — Masri J. Arabic-V uses چ for the Masri letter J. Its sound value is /ʒ/. Therefore J → چ → /ʒ/. Example: Rooj → روچ. This provides an Arabic-script representation that maintains the distinction represented by Masri J.

18. Foreign C/c

Rule AV-F01 — Pronunciation-based C. The Latin letter C/c does not have one fixed Masri value in foreign words. Its Arabic-V representation follows its actual pronunciation.

C = /k/: Caterpillar → كاترپيلر, since the relevant sound is /k/, so C → ك.
C = /s/: center → سنتر, since the relevant sound is /s/, so C → س.

Therefore C + /k/ → ك and C + /s/ → س. C must never be converted solely from its spelling.

19. Foreign X/x

Rule AV-F02 — Pronunciation-based X. Arabic-V distinguishes canonical Masri X/x from foreign Latin x/X. The canonical Masri letter is X → خ → /x/. But a foreign x/X is interpreted according to its pronunciation.

X = /ks/: Taxi → تاكسي, where x → ك + س because the foreign letter represents /ks/.
X = /z/: Xenophon → زينوفون, where X → ز because it is pronounced /z/.

ContextArabic-V
Masri X/xخ
foreign x = /ks/كس
foreign X = /z/ز

The converter must never use a universal X → خ substitution.

20. Canonicalization architecture

Arabic-V should normally be generated from the canonical Masri representation. The preferred pipeline is:

Egyptian input
  ↓
Canonical Masri
  ↓
Masri Standard / DRS / Arabic-V / Masri Basic / Arabic-P

This prevents Arabic-V from becoming an independent spelling-normalization system. The canonical Masri representation determines consonants, vowels, doubled vowels, consonant gemination, sukūn, final forms, Cairene realization, and foreign-word pronunciation. Arabic-V then expresses those decisions in Arabic script.

21. Practical example

Masri Standard: Sayyed katab el dars.
Arabic-V: سَيِّد كَتَبْ اِلْدَرْسْ

The representation is pronunciation-oriented and is intended to reflect Egyptian pronunciation, not MSA pronunciation.

Word 1 — Sayyed

سَيِّد explicitly shows its vowels and the doubled consonant: يّ → yy.

Word 2 — Katab

كَتَبْ is the sequence ك + َ + ت + َ + ب + ْ, i.e. K a t a b → ك َ ت َ ب ْ. The final بْ has mandatory sukūn because there is no vowel after /b/.

Word 3 — el dars

اِلْدَرْسْ — the relevant consonants and vowels are explicitly represented, including sukūn where no vowel follows the consonant.

The complete sentence is therefore:

سَيِّد كَتَبْ اِلْدَرْسْ

This is a practical demonstration of what makes Arabic-V different from ordinary Arabic-P.

25. Information-preservation principle

Arabic-V should not discard information unnecessarily. For example, قٔ contains more information than ء, because it communicates both the underlying ق and its Cairene /ʔ/ realization. Likewise ثۜ contains more information than س when the underlying ث matters, and ذۜ contains more information than ز when the underlying ذ matters.

This makes Arabic-V useful not only for reading, but also for normalization, linguistic analysis, machine learning, conversion between representations, and pronunciation-aware processing.

Arabic-V implementations must preserve the actual base character and combining marks. Unicode normalization, canonical ordering, and rendering behavior must therefore be tested as part of the implementation.

27. Arabic-V versus phonetic transcription

Arabic-V is not unrestricted IPA written in Arabic letters. It remains an orthographic representation of canonical Masri.

For example, قٔ does not merely mean "write the sound /ʔ/". It means: the canonical underlying letter is ق, and its Cairene realization is /ʔ/. Similarly, ثۜ means: the canonical underlying letter is ث, realized as /s/. This is why Arabic-V is an orthography rather than a simple pronunciation transcription.

29. Areas requiring formal specification

The Arabic-V framework is established, but the complete technical standard should continue formalizing:

  • complete vowel mapping
  • all long/doubled-vowel patterns
  • grammatical Tanween
  • final-vowel behavior
  • shadda ordering and interpretation
  • sukūn behavior
  • hamza/alif behavior
  • definite article behavior
  • grammatical endings
  • loanword rules
  • proper names
  • additional Egyptian mergers
  • additional foreign sounds
  • Unicode combining-mark order
  • Unicode normalization
  • renderer requirements

No rule should be inferred merely from conventional MSA spelling.

31. Final definition

Arabic-V is Masri's canonical vocalized Arabic-script representation: a dedicated Egyptian-oriented orthography that combines Arabic letters, Harakat, mandatory sukūn where required, shadda-based doubling, Tanween where required, and defined Masri-specific letters, vowel conventions, and realization markers.

Its fundamental principle is:

One canonical Masri system, multiple controlled representations.

Arabic-V therefore provides an Arabic-script representation that is recognizable, Egyptian-oriented, explicitly vocalized, information-preserving, pronunciation-aware, computationally useful, and extensible.
