دي آر إس  ·  Diaa Romanization System

Type it on any keyboard. All 37 letters.

DRS is the Pinyin-style romanization companion to Masri Tier 2 — same phonemic rules, same 37 letters, spelled with standard Latin-extended characters instead of Masri's own Coptic/Greek-derived script. No custom keyboard needed. DRS is one of five Masri representations — see how it relates to Tier 1, Tier 2, Arabic-V, and Arabic-P.
